# P3 日子感（已记录并开发）

> 承接：轻意外只做访客与氛围，不做毁田。

## 策划记录（已定）

1. **氛围天气**：晴 / 软雨 / 暮色加深 —— 只改天空与粒子，不减速作物、不清空田。  
2. **访客野猫**：软雨时可能出现在屋檐下；点一下留下礼物（猫耳发夹），不踩菜。  
3. **短气泡**：角色或黑猫每日一句，不弹窗打断。  
4. **昨日衣橱 + 简单存档**：刷新后仍穿着上次衣服，菜地进度保留。  
5. **手帐闪光**：一键「拍照」给炫耀反馈（不做社交）。  

明确不做：野猪/大象毁田、霜冻清空、虫害死亡。
