# 玩法策划：先让游戏好玩

> 产品：**蘑菇屋里的小魔女**  
> 定位：种田 + 换装的治愈小院（个人开发可落地）  
> 默认远景：西湖暮色  
> 本文目标：把「好玩」写成可验证的体验，而不是功能清单。

---

## 0. 策划总判断

旧版失败点已经查清：**玩家还没机会评价玩法，就被画面赶走。**  
现在画面方向对了，下一关不是「加系统」，而是：

> **让她愿意再点下一次，并且点完觉得自己变可爱了一点。**

在 Agent Skill、审美素材爆炸的今天，最容易犯的新错是：

1. 把 AI 生成能力当成玩法本身（每天换一张新图，没有节奏）。  
2. 把「好看」做成博物馆（能看不能玩）。  
3. 把「智能」做成复杂助手（打断种地与换装的手感）。

**建议态度：AI 负责加速出装与出氛围；好玩仍靠短循环、可见成长、可炫耀的角色。**

---

## 1. 好玩的定义（本游戏专属）

本游戏的「好玩」不是胜负，而是三种连续快感：

| 快感 | 玩家内心话 | 设计对应 |
|---|---|---|
| **手感爽** | 「点下去有回音」 | 播种落地、浇水水花、收获弹跳、换装小跳 |
| **变好看** | 「她今天更好看了」 | 收获 → 解锁衣服 → 立刻穿上出现在农场 |
| **小日子** | 「这座院子是我的」 | 菜地状态差、西湖暮色、蘑菇屋、黑猫在场 |

如果一个功能不同时服务以上至少一条，**首版不做。**

---

## 2. 核心玩法：双环，但只有一个心跳

### 2.1 心跳（30 秒可完成一次）

```text
选地 → 播种/浇水/收取 → 听到反馈 → 看见变化
```

这是「现在好玩」。没有心跳，换装再多也是空壳。

### 2.2 愿望环（3–10 分钟可见）

```text
收获拿布料/金币 → 解锁一件衣服 → 穿上 → 回农场炫耀 → 想要下一件
```

这是「还想继续玩」。

### 2.3 为什么旧版不够好玩

- 系统很多（抽奖、皮肤主题、道具），但**心跳弱**：空地冷、反馈散。  
- 换装与农场断裂：换完不像同一个人，炫耀感消失。  
- 目标过多：玩家不知道今天「为了什么」点下去。

---

## 3. 首版玩法规格（Fun Vertical Slice）

只做能在一个晚上讲清楚的切片：

### 3.1 场景

1. **农场**（主战场）：西湖暮色远景 + 黄蘑菇屋 + 6 菜畦 + 角色 + 黑猫  
2. **小屋**（情感屋）：进门换装入口，少量蘑菇屋结构呼应  
3. **换装**（愿望屋）：同一母版放大试穿

### 3.2 种田规则（简单到可以背出来）

- 6 块地，全部开局可用（避免「黑地恐惧」）。  
- 作物 4 种：

| 作物 | 周期感 | 作用 |
|---|---|---|
| 小麦 | 最快 | 教程心跳，教播种/收获 |
| 胡萝卜 | 短 | 日常金币 |
| 向日葵 | 中 | 视觉高潮（开花） |
| 草莓 / 星星南瓜 | 稍慢 | 出布料；南瓜成熟带星斑（唯一小魔法） |

- 操作：点地选中 → 底部主按钮随状态变化（播种 / 浇水 / 收获）。  
- **不做**：一键清屏炫技、复杂化肥树、天气惩罚、失败死亡。

### 3.3 换装规则（炫耀优先）

- 部位：帽 / 衣 / 裤鞋（可合并为鞋靴）共 4 槽。  
- 开局就能切换：**黄雨衣套** ↔ **小魔女套**（同脸同身同棕发）。  
- 新衣服来源：收获进度解锁 + 金币购买（**无抽奖**）。  
- 硬规则：农场小人与换装大人同一母版；换完回农场必须一眼看出来。

### 3.4 黑猫（不是宠物系统）

- 固定陪伴剪影 + 月牙项圈。  
- 只会做 3 件事：站旁边、收获时抬抬头、换装时跟进小屋。  
- **不做**喂养、好感度、探险。

### 3.5 要不要参考《星露谷物语》？

**要参考，但只参考「地里的手感」，不参考「星露谷的人生模拟体量」。**

| 借自星露谷（P1 值得学） | 不借（会拖死个人首版） |
|---|---|
| 地块状态一眼可读：干土 / 湿土 / 有苗 / 成熟 | 大门世界、矿洞、战斗、结婚、多人 |
| 浇水有意义，且手感清脆 | 体力条、工具升级树、钓鱼全套 |
| 作物分阶段外形变化，不只靠倒计时数字 | 四季作物表、数十种种子开局全开 |
| 收获时的「多汁」反馈（弹出、音效、轻粒子） | 出货箱深经济、NPC 好感网 |
| 每天回来看见地里自己在长 | 长时间空白种田无反馈 |

对本作的翻译：

> 星露谷教我们：**点一下地，世界要诚实地变一点。**  
> 本作再加上：**变完之后，要让女孩穿得更好看。**

P1 验收不看「像不像星露谷」，只看：六块地是否让人想连续点；浇水/收获是否有回音。

## 4. 进度与「游戏发展」（内容节奏，不是等级墙）

用「日子」而不是「等级」讲成长，降低压迫感。

### 第 0 日（安装后 3 分钟）—— 爱上

- 看见西湖暮色小院，角色挥手。  
- 种 1 次小麦，看到芽。  
- 打开换装，雨衣 ↔ 魔女切换成功。  
- **胜利条件**：对方说「好可爱」或愿意再点。

### 第 1 日（约 15–25 分钟）—— 住下

- 6 地种满并完成一轮收获。  
- 解锁 1 件新单品（围巾/发带级）。  
- 向日葵第一次开花，全场轻庆祝。  

### 第 2–3 日 —— 打扮欲起来

- 草莓/星星南瓜带来布料。  
- 衣柜出现第 3 套日常装（米白+牛仔）。  
- 小屋圆拱窗等结构呼应完成，进门有「回家」感。

### 第 1 周 —— 小而美成形

- 服装约 12–16 件（可拼出多套，不靠数值膨胀）。  
- 远景收集开启：桂林 / 天空之城 / 黄山（用「风景明信片」解锁，不另开玩法）。  
- 拍照框：站在菜地前自拍一张（分享欲，不做社交重度）。

### 明确延后（有了心跳再谈）

| 内容 | 为什么延后 |
|---|---|
| 抽奖/十连 | 破坏换装成就感，易导向霓虹特效 |
| 任务板/成就墙 | 首屏又变功能演示 |
| 宠物养成 | 分流注意力 |
| 多角色/恋爱 | 范围爆炸 |
| 战斗/副本 | 与治愈定位冲突 |
| 赛博等冲突主题皮 | 已证伪 |

## 5. 会话设计：每次打开都要「有事做、有东西变」

玩家每次回来 1–3 分钟，设计成：

1. **一眼看见变化**：哪块地熟了、角色还穿着昨天的衣服。  
2. **一次主操作**：收取或浇水（主按钮直达）。  
3. **一次小愿望**：是否换一件新衣服再走。

禁止每次打开先弹：公告、商店、抽奖、长剧情。

---

## 6. 审美爆炸时代：怎么用，才让游戏更好玩

### 6.1 正确用法（建议采用）

| 用法 | 对好玩的帮助 | 落地方式 |
|---|---|---|
| **AI 加速出装** | 衣柜更新快，愿望环不断 | 固定母版锚点，只生成「衣服贴纸层」 |
| **主题远景包** | 小院常新，不改操作 | 西湖默认；其余当背景收集 |
| **拍照构图** | 把「好看」变成可保存的爽点 | 农场/小屋一键摆拍 |
| **短句氛围** | 情绪连接，不打断操作 | 角色或黑猫 1 句气泡/日 |

### 6.2 危险用法（建议克制）

| 用法 | 风险 |
|---|---|
| 每次进游戏整屏 AI 重绘场景 | 资产不一致，角色「换人」 |
| Agent 自动帮你种完/换好 | 抢走手感，玩家变旁观者 |
| 无限制对话框当主玩法 | 变成聊天产品，种田换装变弱 |
| 靠不断追新画风找爽 | 重演「方向漂移」，永远不收口 |

### 6.3 Agent Skill 对本项目的最优分工

> **人定规则与母版；Agent 产候选服装/远景；人做验收：是否同一女孩、是否抢菜地。**

可做的轻智能（二期）：

- 「今天穿什么」：根据已有衣柜推荐 1 套，不生成新人。  
- 「丰收小记」：把今日收获写成 1 句手帐，增强小日子感。  

首版甚至可以没有智能，只要心跳和换装闭环成立。

---

## 6.5 要不要加意外？（野猫 / 野猪 / 大象 / 坏天气）

**结论：加“轻意外”，不加“毁田惩罚”。**

对象向的治愈小院里，玩家是来过小日子、打扮女孩的。野猪/大象踩坏庄稼这类事件，短期有刺激，长期容易变成：

> 「我好好种的菜没了」→ 烦、委屈、不想打开

这和本作要的第一眼温暖是反方向的。

| 类型 | 建议 | 原因 |
|---|---|---|
| 路过小动物（野猫蹭蹭、小鸟歇菜畦边） | **做** | 日子有呼吸，不破坏进度 |
| 黑猫偶尔特殊动作（跟去小屋、收获抬头） | **做**（已有雏形） | 陪伴感，零系统膨胀 |
| 天气变氛围（西湖暮色加深、小雨光效） | **做氛围，不做惩罚** | 好看；不扣成长、不冻死作物 |
| 良性小事件（多掉 1 布料、蘑菇屋亮灯） | **可做** | 意外＝彩蛋奖励 |
| 野猪/大象毁田、霜冻清空、虫害死亡 | **首版不做** | 惩罚感强，和换装炫耀抢情绪 |

如果一定想要“有点意外”的张力，用这一句替换毁田：

> **访客来了，不是来踩坏的，是来留下一件小礼物/一句气泡的。**

例如：雨天野猫躲到屋檐下 → 第二天衣柜多一副猫耳发夹。  
意外服务换装愿望，而不是打断种田心跳。

排期：P3「日子感」再加 1–2 个轻事件即可；P1/P2 先稳住点地与换装。

## 7. 乐趣加固：5 个低成本高回报设计

1. **选中态**：一块地高亮，主按钮文案跟随（播种/浇水/收获）。  
2. **成熟合唱**：连续收获时短音阶上扬，比单次音效更上瘾。  
3. **换装回场**：穿上后强制切回农场 1.5 秒展示，强化炫耀。  
4. **星星南瓜**：唯一魔法作物，成熟星斑，满足「小魔女」而不开新系统。  
5. **昨日衣橱**：再次打开游戏时，角色仍穿上次的衣服（生活连续感）。

---

## 8. 数值只服务手感（草案）

不追求经济仿真，只保证「今天能解锁一点」。

- 小麦：约 30–60 秒（教程可更短）  
- 胡萝卜：约 2–3 分钟  
- 向日葵：约 5–8 分钟  
- 草莓/星星南瓜：约 10–12 分钟  

目标：一次通勤或睡前会话，至少完成 1 次收获 + 1 次换装冲动。

金币主要用于买种子与下一件衣服；布料用于主题套装。避免双货币焦虑——玩家应感到「种就有」，不是「肝不够」。

---

## 9. 验收：好玩了没有？

找真实玩家（最好就是你对象）按这个顺序测，**不要先介绍系统**：

1. 打开游戏 5 秒：会不会笑一下 / 说可爱？  
2. 30 秒内：会不会自己点地？  
3. 第一次收获后：会不会主动进换装？  
4. 换完回农场：会不会说「哎她变了」？  
5. 合上手机前：会不会说「等下再来收」？

5 问里有 3 个「会」，首版就成立；否则先改反馈与闭环，不改加系统。

## 10. 研发阶段建议（策划视角）

| 阶段 | 只做什么 | 完成定义 |
|---|---|---|
| P0 视觉定稿 | 西湖默认 + 同一女孩三场景 | 审美过关 |
| P1 心跳原型 | 6 地播种浇水收获 + 音效反馈 | 手感好玩 |
| P2 愿望闭环 | 雨衣/魔女/第三套 + 回场展示 | 换装有欲 |
| P3 日子感 | 远景收集、拍照、短气泡 | 想回来 |
| P4 再谈智能 | 推荐穿搭、手帐一句 | 锦上添花 |

**口号：P1 不好玩，P4 免谈。**

---

## 11. 一句话策略

> 用西湖暮色的蘑菇小院留住第一眼，用「点地有回音」留住第一分钟，用「同一女孩换上新衣服站回菜地」留住第一晚；AI 只加速出装与风景，绝不替代这三下快感。
