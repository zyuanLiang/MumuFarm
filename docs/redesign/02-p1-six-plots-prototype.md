# P1 六地可玩原型

> 目标：先验证「点地有回音」，不接换装/抽奖/旧系统。  
> 星露谷参考：**只借地块手感**（干湿、阶段、浇水加速），不借大世界。

## 怎么玩

1. 点选一块菜地（桃色描边 = 选中）。  
2. 底部主按钮随状态变化：播种 / 浇水 / 收获。  
3. 干土生长很慢，浇水后恢复全速（星露谷式激励，无体力条）。  
4. 作物外形分 seed → sprout → growing → mature。

## 本切片包含

- 西湖暮色远景色块（简化）
- 黄蘑菇屋 + 雨衣女孩 + 月牙黑猫剪影
- 6 地 + 4 种作物（周期偏短，方便试手感）

## 不包含

换装、小屋、抽奖、一键全收、旧皮肤主题。
