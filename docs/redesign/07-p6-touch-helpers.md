# P6 粘手播种 · 滑动浇收 · 温柔代劳

> 目标：去掉「选地 → 再点主按钮」的菜单感，让六格菜地像刷漆一样轻。

## 本轮做了什么

1. **粘手播种**：选中种子后，点空地直接播种（种子保持选中，可连续点种）。
2. **滑动浇收**：在菜地上按住拖过，按起手那格的动作锁定（浇水或收获），划过的格子一起处理。
3. **温柔代劳**
   - 点黑猫：帮你浇一格干土
   - 软雨天气：约每 12 秒自动润一格干土
4. 底部主按钮仍保留，给不爱滑动的玩家。

## 刻意不做

- 开局一键全收 / 全浇（会挖空心跳）
- 惩罚性灾害、体力条、复杂工具树

## 手感参考

| 来源 | 借什么 | 不借什么 |
|---|---|---|
| 星露谷 | 拖着浇的身体节奏 | 洒水器科技树 |
| QQ 农场 | 「别让我点六次」的省手诉求 | 冷冰冰一键自动化开局 |

## 验收

- 选小麦后连点 3 块空地，三块都种上
- 干土上滑动，一划多格变湿
- 成熟作物上滑动，一划多格收获
- 点黑猫或切到软雨，能看到代劳反馈文案
