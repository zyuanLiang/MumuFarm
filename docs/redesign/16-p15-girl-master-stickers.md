# P15 女孩母版 + 贴纸层

P14 已能挂图；本轮把**同一女孩母版**钉死，让帽/衣/靴贴纸叠在固定锚点上好看。

## 目标

1. 农场 / 小屋 / 换装页是**同一张脸、同一身比例**（CSS 母版不换）  
2. 只换贴纸：帽、衣、靴（靴层也走 ThemePack URL）  
3. 贴纸画布统一，避免裙摆盖靴、帽檐飘走  
4. 补齐示例美装：剩余衣服/帽子/靴子 + 桂林/天空之城/黄山远景  

## 母版锚点（百分比，相对 `.girl-figure`）

| 槽 | top / bottom | height | 说明 |
|---|---|---|---|
| 脸 `.gf-head` | top 18% | 28% | 永远 CSS |
| 发 `.gf-hair` | top 14% | 26% | 永远 CSS |
| 帽贴 `.gf-hat-art` | top 0 | 26% | 可选图 |
| 衣贴 `.gf-dress-art` | top 40% | 44% | 下沿约 84%，给靴留空 |
| 靴贴 `.gf-boots-art` | bottom 0 | 16% | 可选图；无图用 CSS |

## 贴纸画布约定

- 衣：`viewBox="0 0 80 100"`，领口约 y=12–20，下摆止于 y≈78  
- 帽：`viewBox="0 0 80 48"`，帽檐贴底边  
- 靴：`viewBox="0 0 80 28"`，双靴贴底  

## 不做

- 新解锁规则、新套装玩法  
- 换脸/换发型（母版锁定）  
- 商城买皮
