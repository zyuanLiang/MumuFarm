# P26 女孩头像母版 PNG

水彩立绘包补上**女孩头像母版**（脸+发一体 PNG）。帽/衣/靴仍分层贴纸；其他主题无槽时继续用 CSS 脸。

## 本轮

1. `ThemeAssets.girlHead` + `girlHeadArtUrl()`  
2. `GirlFigure`：有头像 PNG 时隐藏 CSS 脸发，叠 `.gf-head-art`  
3. `public/skins/png-portrait/girl/girl-head.png`（160×200 透明）  
4. 切到水彩立绘提示「女孩头像也换真了～」  

## 不做

- 每套衣服换一张整身立绘（仍用帽衣靴分层）  
- 换发型玩法 / 捏脸  
- 示例美装、雨紫主题强行换脸（保持 CSS 对照）
