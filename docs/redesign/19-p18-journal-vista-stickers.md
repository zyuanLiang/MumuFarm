# P18 手帐远景贴纸

拍照入册的小日子页，天空条也要能挂真远景——和农场同一套 ThemePack 槽。

## 本轮

1. 手帐卡 `journal-card-sky`：有 `vistaArtUrl` 用图，无图回退 CSS 渐变  
2. 入册时记下 `themeId`，回看尽量用拍照当天的主题远景贴  
3. 手帐页背景跟随主题色板（`--cream` / `--wood`）  

## 槽位

`ThemePack.assets.vistaBg[vista]` → 手帐卡天空（与农场远景同一 URL）

## 不做

- 真实相机、社交分享  
- 手帐封面商店 / 滤镜编辑器
