## 0. 复盘结论（设计前提）

旧版失败的不是功能数量，而是**第一印象与产品表达**：

| 旧版问题 | 新版必须做到 |
|---|---|
| 农场首屏空旷、冰冷，中央深色地块像培养皿 | 首屏满是阳光、草地、作物、角色、生活气息 |
| 小屋像悬浮在黑暗虚空的半成品几何模型 | 小屋是有窗外风景、有家具、有阳光的「家」 |
| 霓虹按钮 + Emoji 作物 + 写实阴影 + 暗色房间混搭 | 全游戏统一一套软水彩卡通视觉语言 |
| 第一眼只看到计数器、按钮、空地 | 第一眼看到「我想经营这座可爱农场」 |
| README 写治愈，画面像孤立诡异 | 画面必须先于文案，自己讲出「治愈」 |

**本阶段不做：** 任务系统、宠物、更多作物、赛博/神泉皮肤、十连抽扩展、复杂数值。  
**本阶段只定：** 图片风格、页面构图、前十秒情绪、核心玩法（种田 + 换装）。

---

## 1. 产品一句话

**阳光下的小小农场：种菜养家，换衣服打扮自己。**

双核心，权重对等：

1. **种田** —— 给节奏、给收获、给「这座农场是我的」。
2. **换装** —— 给身份、给好看、给「我想一直看下去」。

两者通过同一套美术与同一位角色绑定：角色永远出现在农场与小屋里，换装结果立刻出现在场景中。

## 2. 美术方向（Art Bible）

### 2.1 风格关键词

- 软水彩卡通（soft watercolor-cartoon）
- 暖阳光、清晨、草地香气
- 圆润、手绘、有温度
- 像「能住进去的插画」，不是 UI 演示，不是暗黑梦核

### 2.2 禁止清单（硬规则）

- 禁止霓虹、赛博、紫光描边、强发光按钮
- 禁止 Emoji 当作物/道具主视觉
- 禁止大面积纯黑/虚空背景（尤其小屋）
- 禁止写实照片阴影 + 扁平按钮混用
- 禁止首屏堆功能入口、开发说明、数值墙
- 禁止把地块做成深色棺形/培养皿形容器

### 2.3 色彩系统

| 角色 | 色名 | 参考值 | 用途 |
|---|---|---|---|
| 天空 | Soft Blue | `#A8D4F0` | 天空、清爽感 |
| 草地 | Meadow Green | `#7CB87A` | 农场地面主色 |
| 阳光 | Sun Amber | `#F2C14E` | 高光、金币、成熟提示 |
| 木色 | Cream Wood | `#F7E8D0` | 小屋、家具、面板 |
| 泥土 | Warm Brown | `#C49A6C` | 地块（暖褐，绝不发黑发冷） |
| 点缀 | Peach Accent | `#F0A07A` | 主 CTA、角色腮红、围巾等 |
| 叶片 | Leaf Sage | `#9BBF8A` | 作物叶片、次级按钮 |

整屏氛围：**偏暖、偏亮、偏软**。阴影用暖色半透明，不用冷灰/纯黑。

### 2.4 造型语言

- **角色**：Q 版圆润、大眼睛、表情清晰；永远是画面情感锚点。
- **作物**：手绘植株，有体积与叶片层次；成熟时微微晃动，不靠闪烁霓虹。
- **地块**：暖色翻土，边缘柔和、略不规则；空地也要像「刚翻好的菜畦」，不像 UI 槽位。
- **按钮**：圆角、低对比、材质偏木质/布艺；主按钮用桃色填充，次按钮用奶油色描边。
- **字体（实现阶段再定具体字体文件）**：标题用手写感或圆润展示字体；正文用清晰圆体。避免 Inter / Roboto / 系统默认栈当主视觉。

## 3. 布局设计（先构图，再功能）

### 3.1 信息架构（极简）

只保留三个主场景：

```text
农场 Home  ←→  小屋 Cottage  ←→  换装 Wardrobe
     ↑               ↑
   （种田）        （回家 / 打扮）
```

次级层（半屏抽屉，不抢首屏）：

- 种子选择（从底部滑出）
- 背包（收获物与少量道具）
- 设置（音效、重置等，藏在角落）

**旧版抽奖 / 多主题皮肤切换 / 复杂 HUD 暂不进入首版构图。**

### 3.2 农场首屏构图（手机竖屏 9:16）

目标：第一视口 = **一幅完整插画**，不是仪表盘。

```text
┌─────────────────────────┐
│ ☀ 天空渐变 + 软云        │  ← 全出血背景（不是色块底板）
│                         │
│  [金币]          [小屋]  │  ← 极小浮层，不抢戏
│                         │
│      小木屋剪影          │
│                         │
│   角色 + 6 块暖色菜畦    │  ← 视觉中心：人 + 地 + 苗
│   （有草、花、阳光）      │
│                         │
│      [ 浇水 / 播种 ]     │  ← 唯一主 CTA
│   (次级：背包 · 种子)    │
└─────────────────────────┘
```

硬规则：

1. **品牌/角色优先**：角色必须出现在首屏中景，不能只剩地块和按钮。
2. **一个主行动**：首屏底部只强调一个动作（新手期是「播种」，之后随上下文变成「浇水」或「收获」）。
3. **禁止首屏**：任务列表、统计条、抽奖入口、开发说明、多排图标。
4. **地块数量首版固定 6**（2×3），排得紧凑有「田」的感觉，避免中间一大块空洞。

### 3.3 小屋布局

```text
┌─────────────────────────┐
│ ← 回农场                 │
│                         │
│   窗光 + 窗帘 + 窗外田野 │  ← 必须看见室外，打破封闭感
│                         │
│   床 · 桌 · 花 · 地毯    │  ← 家具贴地、有投影、成套
│         角色站立         │
│                         │
│        [ 换装 ]          │
└─────────────────────────┘
```

硬规则：

- 房间有四面关系：墙、地板、窗、门口；**禁止角色/家具浮在纯色或纯黑里**。
- 窗外必须能看到农场色（绿草/天空），让小屋与农场是同一世界。
- 家具成套、有生活痕迹（茶杯、花、被子），避免「灰色占位方块」。

### 3.4 换装布局

```text
┌─────────────────────────┐
│ ← 返回                   │
│                         │
│      大尺寸全身角色      │  ← 绝对主角，占屏 55%+
│      （实时换装预览）     │
│                         │
│  帽 | 衣 | 裤 | 鞋       │  ← 分类 Tab，暖色轻面板
│  ○ ○ ○ ○  单品横滑      │
│                         │
│        [ 穿上 ]          │
└─────────────────────────┘
```

硬规则：

- 换装是「看自己变好看」，不是「管理皮肤资源列表」。
- 单品图标必须是同一套插画风格，禁止用文字列表或霓虹卡片墙。
- 穿上后立刻同步到农场与小屋中的角色。

## 4. 前十秒体验（情绪脚本）

玩家打开游戏后的目标不是「理解系统」，而是：**感到温暖，并亲手种下一棵菜。**

| 时间 | 画面 | 玩家感受 | 系统行为 |
|---|---|---|---|
| 0–2s | 晨光农场淡入：草动、云慢飘、角色挥手 | 「好可爱 / 好暖和」 | 无弹窗、无教程墙 |
| 2–5s | 角色气泡：「今天也来种一点吧～」+ 一块地微微发光 | 「我知道要点哪里」 | 只高亮 1 块地 + 1 个主按钮 |
| 5–10s | 点击播种 → 种子落入 → 冒出小芽 + 轻快音效 | 「有反馈、好舒服」 | 立即给成长感（短教程作物） |

十秒内**不允许**出现：抽奖、升级弹窗、皮肤商城、长说明、多步骤强制引导。

成功标准（给人看时用）：

> 对方第一眼会不会说「好可爱」或「好暖和」，而不是沉默、皱眉或「这什么玩意」。

## 5. 玩法设计（在视觉立住之后）

### 5.1 核心循环（双环）

```text
        ┌── 种田环 ──────────────────┐
        │ 选种 → 播种 → 浇水/等待     │
        │ → 收获 → 金币/材料          │
        └──────────┬─────────────────┘
                   │ 解锁服装与装饰
                   ▼
        ┌── 换装环 ──────────────────┐
        │ 获得单品 → 试穿 → 穿上      │
        │ → 角色出现在农场/小屋       │
        └──────────┬─────────────────┘
                   │ 想要下一套衣服
                   ▼
                 回到种田
```

种田提供节奏与资源；换装提供情感与「继续玩的理由」。两者互相喂养。

### 5.2 种田（首版范围）

- **地块**：6 块，全部一开始可用（降低空旷与「未解锁黑地」的恐惧感）。
- **作物首版只做 4 种**（质量 > 数量）：
  1. 小麦 —— 最快，教程作物  
  2. 胡萝卜 —— 短周期，新手日常  
  3. 向日葵 —— 中周期，强视觉高潮（开花）  
  4. 草莓 —— 稍慢，高收益，解锁换装币更多  
- **操作**：点地播种 / 点地收获；上下文主按钮辅助「全部浇水」或「收取成熟」。
- **成长反馈**：芽 → 苗 → 成株 → 成熟；每阶段外形变化清楚，倒计时弱化到角落，**不靠冷色进度条统治画面**。
- **资源**：金币（买种子/买衣服）+ 布料碎片（换装材料，由收获掉落）。

### 5.3 换装（首版范围）

- **部位**：帽、上衣、下装、鞋（4 槽）。
- **初始装**：一套「农场日常」（草帽 + 背带裤），保证开局角色就可爱。
- **获取**：
  - 新手礼：再送 1 顶发带 / 1 条围巾（立刻可换，建立「换装很爽」）。
  - 其余用金币或布料在小屋衣柜解锁（简单列表，不做抽奖）。
- **展示**：农场与小屋共用同一套穿戴状态。

### 5.4 明确砍掉 / 冻结（相对旧版）

| 旧内容 | 首版决策 | 原因 |
|---|---|---|
| 赛博空间 / 神圣神泉等冲突皮肤 | **删除** | 视觉语言打架，是第一印象杀手 |
| 抽奖 / 十连 | **冻结** | 功能演示感强，且易导向霓虹特效 |
| 大量作物与稀有神豆 | **砍到 4 种** | 先把每种作物画好看 |
| 复杂道具增益 | **冻结** | 干扰前十秒与主循环 |
| 天气系统特效堆叠 | **简化为氛围** | 只服务「阳光农场」情绪 |
| 小屋黑暗虚空场景 | **重做** | 致命负面第一印象 |

### 5.5 进度节奏（首版）

1. **开场**：已有 1 颗小麦种子，角色可换 2 套基础装。  
2. **第一次收获**：解锁胡萝卜 + 一件上衣。  
3. **向日葵第一次开花**：全屏轻庆祝（花瓣、暖光），强化「好看」记忆点。  
4. **草莓解锁**：衣柜出现第二排单品。  

不做等级墙压迫；解锁跟「你种过什么 / 收获几次」绑定，玩家感到是生活展开，不是刷级。

## 6. 动效与声音（服务情绪，不服务炫技）

至少 3 个有意动效（实现阶段必须落地）：

1. **晨光呼吸**：天空与草叶极慢起伏（进场就有生命感）。  
2. **播种落地**：种子弧线落入泥土 → 土面轻颤 → 冒芽。  
3. **换装切换**：衣物柔和替换 + 角色小跳/转圈确认。

音效方向：木琴/柔和拨弦、鸟鸣远景；禁止电子噪、恐怖低音、过响 UI 哔哔声。

## 8. 验收标准（给「对象第一眼」用的）

请用这 5 条判断设计是否成功——**任何一条失败，就还不能开工堆功能**：

1. 截掉 UI 文字后，仍能看出这是「可爱阳光农场」。  
2. 小屋不会让人联想到密室、梦核、恐怖游戏。  
3. 作物、按钮、角色、房间属于同一套画风。  
4. 十秒内能完成一次「播种并看到芽」。  
5. 换装后，角色在农场里明显变了，且更好看。
