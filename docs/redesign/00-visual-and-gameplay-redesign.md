## 0. 复盘结论（设计前提）

旧版失败的不是功能数量，而是**第一印象与产品表达**：

| 旧版问题 | 新版必须做到 |
|---|---|
| 农场首屏空旷、冰冷，中央深色地块像培养皿 | 小院有生活感，菜畦清楚可点，角色一眼可见 |
| 小屋像悬浮在黑暗虚空的半成品几何模型 | 小屋是可摆弄的「口袋娃娃屋」 |
| 霓虹按钮 + Emoji 作物 + 写实阴影 + 暗色房间混搭 | 全游戏统一奶油纸片 + 大色块视觉语言 |
| 第一眼只看到计数器、按钮、空地 | 第一眼想「我要住进这个小院子、打扮这个角色」 |
| README 写治愈，画面像孤立诡异 | 画面必须先于文案，自己讲出「小而美的日子」 |

**本阶段不做：** 任务系统、宠物、更多作物、赛博/神泉皮肤、十连抽、复杂数值。  
**本阶段只定：** 画风、构图、前十秒情绪、核心玩法（种田 + 换装）。

## 1. 产品一句话（v2 锁定）

> **奶油纸片小院：种一点喜欢的蔬果，穿今天喜欢的衣服，过自己的小日子。**

不是广阔农场，也不是满屏花草的童话海报，而是一个**角色真正住得进去的小院子**。

双核心：

1. **种田** —— 节奏、收获、「这片小菜畦是我的」。
2. **换装** —— 身份、好看、「我想一直打扮她」。

农场里角色虽小，也必须能看出今天的帽子和裙子；换装页放大的是**同一个纸片娃娃母版**，绝不能像换了另一个人。

## 2. 方向选型（已决策）

参考对比后的排序：**先做 A＋C，再视需要掺一点 B 的手绘温度。不做 D 的真 3D。**

| 方向 | 借鉴什么 | 决策 |
|---|---|---|
| **A．奶油色纸片农场**（《My Dear Farm》类） | 清晰轮廓、大色块、圆润角色、少写实纹理；固定视角方便拆资产 | **基础画风（采用）** |
| **B．手帐绘本小院**（《兔兔岛》类） | 手绘温度、小物件生活感；不堆复杂光影 | **氛围参考**（可少量纸感/线稿，不作主风格） |
| **C．口袋娃娃屋＋换装**（《Pocket Love》类） | 角色/衣服/房间像可收集小玩具；换装是展示欲中心 | **换装与小屋表现（采用）** |
| **D．软糖立体农场**（《Ooblets》类） | 圆润造型、明亮配色 | **只借配色与圆润感，不做 3D** |

### 2.1 为什么否决「精细水彩插画」作为主方向

v1 概念图（`concept-farm-home.png` 等）温暖可爱，但作为可落地首版有风险：

1. **画面偏满** —— 花草屋瓦纹理抢戏，角色和菜地不够显眼；角色还可能挡住操作区。  
2. **偏黄偏复古** —— 后续清爽短裙、雨衣、运动装容易和背景打架。  
3. **整图好看 ≠ 资产好做** —— 每件衣服、每个生长阶段都要同一视角/光照/笔触；不能靠反复生成整张海报。

**调整原则：保留温暖，减少纹理；保留可爱，强化角色；背景退一点，种田和换装更显眼。**

参考图：[`concepts/ref-usagi-shima.png`](./concepts/ref-usagi-shima.png)（《兔兔岛》—— 借亲切感与轻布置，不改主角为动物）。

## 3. 美术方向（Art Bible v2）

### 3.1 风格关键词

- 奶油纸片 / 贴纸拼贴（cream paper-cut / sticker）
- 大色块、软描边、少纹理
- 清爽暖色（奶白 + 鼠尾草 + 蜜桃 + 天空蓝 + 牛仔蓝）
- 固定略俯视小院视角（便于模块化拼装）
- 角色 = 可换装的纸片娃娃母版

### 3.2 禁止清单（硬规则）

- 禁止霓虹、赛博、紫光、强发光按钮
- 禁止 Emoji 当作物/道具主视觉
- 禁止大面积纯黑/虚空背景
- 禁止写实泥土碎石、厚重木纹、复杂织物纹理当主表现
- 禁止满屏花草/远山抢戏
- 禁止首屏功能墙、开发说明、数值条霸屏
- 禁止地块做成深色棺形/培养皿
- 禁止农场小人与换装大人为两套比例/脸型

### 3.3 色彩系统（更清爽，少复古黄）

| 角色 | 色名 | 参考值 | 用途 |
|---|---|---|---|
| 纸底 | Cream | `#FFF8EE` | 地面、面板、房间墙 |
| 草地 | Sage | `#9BC09A` | 草坪色块 |
| 天空 | Soft Sky | `#B7D8F0` | 天空、清爽感 |
| 点缀 | Peach | `#F3A989` | 主 CTA、腮红、部分单品 |
| 蜂蜜 | Honey | `#F0C75E` | 金币、成熟提示 |
| 浅木 | Soft Wood | `#E8D5B5` | 围栏、家具、小屋 |
| 牛仔 | Denim | `#7FA3C9` | 日常穿搭、清爽对比 |
| 菜畦 | Soft Soil | `#D2A679` | 六块柔和轮廓菜畦（绝不发黑） |

阴影：极淡暖色半透明；几乎不做写实投影。

### 3.4 造型与资产规则（为个人开发可维护）

1. **固定视角**：小院略俯视；小屋正面娃娃屋；换装正面全身母版。  
2. **模块拆分**：房子 / 围栏 / 六菜畦 / 作物四阶段 / 角色母版 / 衣帽裤鞋分层 —— 分别绘制，再组合。  
3. **角色母版稳定**：头身比、关节锚点、脸型固定；衣服按同一锚点叠穿。  
4. **作物靠形状辨认**：小麦、胡萝卜、向日葵、草莓 —— 鲜明剪影优先，细节其次。  
5. **道具克制**：全场只留少量记忆点（格纹桌布、晾衣绳、门边雨靴），不堆饰品。

## 4. 布局设计（相对 v1 的构图调整）

玩法结构不变：三场景、六地、四作物、四换装部位。

| v1 构图倾向 | v2 调整 |
|---|---|
| 大房子、远山、密集花草 | 小屋外墙 + 窗 + 围栏，背景简洁 |
| 写实泥土碎石菜畦 | 六块形状清楚、颜色柔和的小菜畦（操作焦点） |
| 大量细碎装饰 | 少量记忆点：格纹桌布、晾衣绳、门边雨靴 |
| 角色与背景一样精细 | 背景克制；角色与衣服是视觉重点 |
| 换装主要在室内看 | 换好后回农场，穿搭仍清楚可见 |

### 4.1 农场首屏（9:16）

```text
┌─────────────────────────┐
│ 奶油纸底 + 浅天空色块     │
│ [金币]            [小屋] │  ← 极小芯片，不抢戏
│   小屋外墙 / 窗 / 围栏    │  ← 小，靠边，不作海报主体
│  晾衣绳 · 雨靴（记忆点）  │
│                         │
│   ★ 2×3 柔和菜畦 ★       │  ← 视觉与操作中心
│   角色站在畦旁（不挡地）  │
│                         │
│        [ 播种 ]          │  ← 唯一主 CTA（桃色）
└─────────────────────────┘
```

### 4.2 小屋（口袋娃娃屋）

- 正面剖视房间，家具贴地、成套、像玩具。  
- 窗外必须看到小院色块（绿草/天空），同一世界。  
- 主按钮：「换装」。

### 4.3 换装

- 同一母版放大至屏高约 55–65%。  
- 帽 / 衣 / 裤 / 鞋 四槽；单品是贴纸式图标。  
- 「穿上」后同步农场与小屋。

## 5. 前十秒体验

| 时间 | 画面 | 感受 | 系统 |
|---|---|---|---|
| 0–2s | 奶油小院淡入：草色块、角色挥手 | 「好清爽、好想住」 | 无弹窗 |
| 2–5s | 气泡「种一点喜欢的吧～」+ 一块菜畦轻高亮 | 「知道点哪里」 | 只高亮 1 地 + 1 按钮 |
| 5–10s | 播种 → 冒芽 + 轻快音效 | 「有反馈」 | 短周期教程小麦 |

禁止十秒内出现抽奖、升级墙、皮肤商城、长说明。

成功标准：对方第一反应是「好可爱 / 想打扮她 / 想要这个小院」，而不是皱眉或害怕。

## 6. 玩法设计（范围不变，表达升级）

### 6.1 双环

```text
选种→播种→等待/浇水→收获→金币/布料
                ↓
         解锁服装单品
                ↓
     试穿→穿上→回农场展示 → 想要下一套 → 再种田
```

### 6.2 种田首版

- 6 块地全部可用。  
- 作物 4 种：小麦、胡萝卜、向日葵、草莓。  
- 成长靠外形阶段变化；倒计时弱化到角落。

### 6.3 换装首版

- 4 部位；开局一套农场日常 + 新手再送 1–2 件可立刻换的单品。  
- **不做抽奖**；用金币/布料在衣柜解锁。  
- 穿搭风可以是米白、浅绿、牛仔蓝日常风，不锁死甜粉。

### 6.4 冻结 / 删除（相对旧代码）

赛博/神泉皮肤、抽奖十连、神豆类作物膨胀、复杂道具、黑暗小屋 —— 全部冻结或删除。

---

## 7. 动效（至少 3 个）

1. 小院色块轻呼吸（草/天空极慢起伏）。  
2. 播种：贴纸落入菜畦 → 冒芽弹一下。  
3. 换装：衣片替换 + 角色小跳确认。

---

## 8. 验收标准

1. 截掉文字后，仍像「可打扮的奶油纸片小院」，不像功能 demo 或恐怖空屋。  
2. 六块菜畦一眼可辨、可点，不被背景抢走。  
3. 农场角色与换装角色是同一母版。  
4. 十秒内能播种并看到芽。  
5. 换上清爽短裙/雨衣/牛仔单品，不与背景打架。  
6. 资产能按「母版 + 分层」维护，而不是只会出整张海报。
