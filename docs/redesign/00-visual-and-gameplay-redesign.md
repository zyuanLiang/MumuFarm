## 0. 复盘结论（设计前提）

旧版失败的不是功能数量，而是**第一印象与产品表达**：

| 旧版问题 | 新版必须做到 |
|---|---|
| 农场首屏空旷、冰冷，中央深色地块像培养皿 | 小院有生活感，菜畦清楚可点，角色一眼可见 |
| 小屋像悬浮在黑暗虚空的半成品几何模型 | 小屋是可摆弄的「口袋娃娃屋」 |
| 霓虹按钮 + Emoji 作物 + 写实阴影 + 暗色房间混搭 | 全游戏统一奶油纸片 + 大色块视觉语言 |
| 第一眼只看到计数器、按钮、空地 | 第一眼想「我要住进这个小院子、打扮这个角色」 |
| README 写治愈，画面像孤立诡异 | 画面必须先于文案，自己讲出「小而美的日子」 |

**本阶段不做：** 任务系统、宠物养成、更多作物、赛博/神泉皮肤、十连抽、复杂数值。  
（允许一只小猫作**视觉陪伴**，不做养成玩法。）  
**本阶段只定：** 画风、构图、前十秒情绪、核心玩法（种田 + 换装）。

## 1. 产品一句话（v4 锁定）

### **蘑菇屋里的小魔女**

> **穿着雨靴种菜，也种一点小魔法。**

生产画风：奶油纸片小院（清爽可操作）＋ 口袋娃娃屋换装。  
识别组合（固定，不再来回换普通农舍）：

> **黄色蘑菇屋 ＋ 同一位女孩（日常黄雨衣 / 打扮时魔女裙）＋ 带月牙项圈的小黑猫。**

「魔女」先体现在造型与生活气氛，**不等于**魔法技能、药水合成或战斗。葡萄紫只出现在帽子、浇水壶、少量魔法细节；主体仍是奶油黄与草绿。

双核心不变：种田给节奏，换装给打扮欲；农场小人与换装大人必须是**同一母版**。

作物：大多是熟悉蔬果；只挑一种带轻微魔法变化（如南瓜成熟时星形亮斑）。

## 2. 方向选型（已决策）

参考对比后的排序：**先做 A＋C，再视需要掺一点 B 的手绘温度。不做 D 的真 3D。**

| 方向 | 借鉴什么 | 决策 |
|---|---|---|
| **A．奶油色纸片农场**（《My Dear Farm》类） | 清晰轮廓、大色块、圆润角色、少写实纹理；固定视角方便拆资产 | **基础画风（采用）** |
| **B．手帐绘本小院**（《兔兔岛》类） | 手绘温度、小物件生活感；不堆复杂光影 | **氛围参考**（可少量纸感/线稿，不作主风格） |
| **C．口袋娃娃屋＋换装**（《Pocket Love》类） | 角色/衣服/房间像可收集小玩具；换装是展示欲中心 | **换装与小屋表现（采用）** |
| **D．软糖立体农场**（《Ooblets》类） | 圆润造型、明亮配色 | **只借配色与圆润感，不做 3D** |

### 2.1 为什么否决「精细水彩插画」作为主方向

v1 概念图（`concept-farm-home.png` 等）温暖可爱，但作为可落地首版有风险：

1. **画面偏满** —— 花草屋瓦纹理抢戏，角色和菜地不够显眼；角色还可能挡住操作区。  
2. **偏黄偏复古** —— 后续清爽短裙、雨衣、运动装容易和背景打架。  
3. **整图好看 ≠ 资产好做** —— 每件衣服、每个生长阶段都要同一视角/光照/笔触；不能靠反复生成整张海报。

**调整原则：保留温暖，减少纹理；保留可爱，强化角色；背景退一点，种田和换装更显眼。**

参考图：[`concepts/ref-usagi-shima.png`](./concepts/ref-usagi-shima.png)（《兔兔岛》—— 借亲切感与轻布置，不改主角为动物）。

### 2.2 四风格对照板：你更喜欢 2 与 4（气质参考，不是整套照搬）

对照板：[`concepts/ref-four-styles-board.png`](./concepts/ref-four-styles-board.png)

| 板面 | 名称 | 我们借什么 | 我们不整套照搬什么 |
|---|---|---|---|
| **2 · 酸甜魔女花园** | 故事感、尖帽大剪影、蘑菇小屋记忆点、黑猫伙伴、奇趣作物表情 | 默认整屏深紫夜空 + 暗森林（容易回到「第一眼害怕」） |
| **4 · 雨后像素小镇** | 高对比主角色（黄雨衣）、暖窗灯光、湿润生活感、清晰可读的小物件 | 默认整屏雨夜暗调 + 完整像素管线（首版成本高） |

**落地合成（v3）：**

> 生产画风仍是 **奶油纸片 A＋口袋娃娃屋 C**；  
> **2 / 4 的喜欢点，变成「可换的装与记忆点道具」**，而不是把首屏永久改成暗夜。

具体落入首版：

1. **共用布局**（四格板已经统一，直接采用）：左上菜单 · 右上金币 · 中景小屋+角色+宠物 · 下半 2×3 菜畦 · 底部浇水主按钮。  
2. **蘑菇小屋**作小院记忆点剪影（来自 2），窗户带一点暖光（来自 4）。  
3. **开局可换两套强识别穿搭**：酸甜魔女套（尖帽重点）＋ 黄雨衣套（高对比重点）。  
4. **一只小猫**作陪伴剪影（先视觉伙伴，不做宠物养成系统）。  
5. **夜色 / 雨景**只作为后续「天气或主题滤镜」候选，**不作为第一次打开的默认底**。

### 2.5 背景升级（v5 · 远景可炫，近景仍清楚）

前台锁定不变：黄蘑菇屋、角色、2×3 菜畦、浇水 CTA。  
**可以换炫的是远景层**——像舞台天幕，不压操作区。

原则：

1. 远景可以有天空之城、桂林山水、西湖、黄山云海等「一眼有故事」的天际线。  
2. 远景必须虚、远、简化；禁止把花草城堡堆到角色和菜地中间。  
3. 默认仍建议偏明亮暖色；深暮色可以作主题皮肤，不作唯一开局。  
4. 首版可先定一个默认远景，其余当可解锁「窗外风景 / 主题背景」。

## 3. 美术方向（Art Bible v5）

### 3.1 风格关键词

- 奶油纸片 / 贴纸拼贴（cream paper-cut / sticker）
- 大色块、软描边、少纹理
- 清爽暖色底；穿搭可出现薰衣草紫 / 亮黄雨衣（服装色，不是背景虚空色）
- 固定略俯视小院；蘑菇小屋暖窗作记忆点
- 角色 = 纸片娃娃母版；小猫 = 小型陪伴剪影

### 3.2 禁止清单（硬规则）

- 禁止霓虹、赛博、强发光按钮
- 禁止 Emoji 当作物/道具主视觉
- 禁止大面积纯黑/虚空背景
- 禁止把「深紫夜空 / 雨夜小镇」做成唯一默认首屏（可作后期主题）
- 禁止写实泥土碎石、厚重木纹、复杂织物纹理当主表现
- 禁止满屏花草/近景装饰抢戏（**远景天际线可以炫，但必须退后虚化**）
- 禁止首屏功能墙、开发说明、数值条霸屏
- 禁止地块做成深色棺形/培养皿
- 禁止农场小人与换装大人为两套比例/脸型
- 禁止完整像素管线作为首版生产标准

## 4. 布局设计（对齐四风格板骨架）

玩法结构不变：三场景、六地、四作物、四换装部位；**增加小猫视觉伙伴**。

### 4.1 农场首屏（9:16）

```text
┌─────────────────────────┐
│ [≡]              [币 +] │
│ 奶油纸底 + 浅天空        │
│   黄蘑菇屋（固定标志）   │
│   同一女孩 + 月牙黑猫    │
│                         │
│  2×3 菜畦（状态差清楚）  │
│  ★ 一块选中高亮 ★        │
│  空地 / 幼苗 / 成熟混排  │
│                         │
│      ( 浇水壶 CTA )      │
└─────────────────────────┘
```

硬规则：加状态，不加花草；角色不挡菜地。

### 4.2 小屋（下一步小改，本轮未重画）

- 已舒服的奶油室内 + 雨衣女孩母版可保留。  
- 待改：圆拱窗呼应外立面；保留蘑菇摆件；床头或地毯一点蘑菇弧线。改两三点即可。

### 4.3 换装

- 同一母版放大；先验证「雨衣 ↔ 魔女」同脸同身。  
- 本轮保持棕色短发；粉色假发等后置。  
- UI 文案在游戏里排版，概念图尽量少烘焙文字。

## 5. 前十秒体验

| 时间 | 画面 | 感受 | 系统 |
|---|---|---|---|
| 0–2s | 奶油小院淡入：草色块、角色挥手 | 「好清爽、好想住」 | 无弹窗 |
| 2–5s | 气泡「种一点喜欢的吧～」+ 一块菜畦轻高亮 | 「知道点哪里」 | 只高亮 1 地 + 1 按钮 |
| 5–10s | 播种 → 冒芽 + 轻快音效 | 「有反馈」 | 短周期教程小麦 |

禁止十秒内出现抽奖、升级墙、皮肤商城、长说明。

成功标准：对方第一反应是「好可爱 / 想打扮她 / 想要这个小院」，而不是皱眉或害怕。

## 6. 玩法设计（摘要）

完整策划见：[01-gameplay-fun-first.md](./01-gameplay-fun-first.md)

### 6.1 双环

```text
选种→播种→等待/浇水→收获→金币/布料
                ↓
         解锁服装单品
                ↓
     试穿→穿上→回农场展示 → 想要下一套 → 再种田
```

心跳是 30 秒可完成的点地反馈；愿望是换装炫耀。首版不做抽奖、任务墙、宠物养成。

### 6.2 种田首版

- 6 块地全部可用；主按钮跟随选中地状态（播种/浇水/收获）。  
- 作物：小麦、胡萝卜、向日葵、草莓/星星南瓜（唯一轻魔法）。  

### 6.3 换装首版

- 开局雨衣 ↔ 魔女同母版可切；新装靠收获与金币解锁。  
- 穿上后回农场短展示，强化「她变好看了」。

### 6.4 冻结 / 删除

赛博/神泉皮、抽奖十连、作物膨胀、复杂道具、黑暗小屋、宠物养成、战斗 —— 冻结。

### 6.5 发展节奏（摘要）

- 第 0 日：种一次 + 换一次，先可爱。  
- 第 1 日：种满一轮 + 新单品 + 向日葵开花。  
- 第 1 周：12–16 件衣、远景收集、拍照。  
- AI/Agent：只加速出装与远景，不替代手感。
